Modules Principaux

Les 6 modules qui composent le système de sessions

SessionLogger

Enregistre les messages et métadonnées des sessions en cours.

  • Écriture atomique
  • Validation des données
  • Gestion des erreurs

SessionLoader

Charge les sessions existantes depuis le disque.

  • Désérialisation
  • Vérification d'intégrité
  • Reconstruction

SessionIndex

Index persistant de toutes les sessions.

  • Indexation automatique

  • Intégration CLI

Fonctionnalités Clés

Ce que permet le système de sessions

1

Reprise Automatique

Reprenez exactement où vous vous êtes arrêté, même après avoir fermé votre terminal. Le système détecte automatiquement votre dernier TTY et charge la session correspondante.

Transparente - Aucun effort requis
2

Fork & Rewind

Expérimentez avec différents chemins à partir d'un point de conversation. Créez des branches (fork) pour tester des idées, ou revenez en arrière (rewind) à un message spécifique.

Gestion des Sessions

Organisez vos sessions avec des fonctionnalités pratiques : épinglez vos sessions importantes, renommez-les pour plus de clarté, ou supprimez celles que vous n'utilisez plus.

/pin Épingler
/rename <titre> Renommer
/delete Supprimer
4

Performance Optimisée

Le système est optimisé pour être ultra-rapide, même avec des centaines de sessions. Grâce à un cache intelligent et une réconciliation automatique, le listage des sessions reste instantané.

Avec cache: ~4ms
Sans cache: ~35ms

Architecture & Principes de Conception

Comment le système est construit pour être robuste, performant et portable

Atomicité

Écritures atomiques via fichiers temporaires + rename pour éviter toute corruption.

# Pattern utilisé
1. Écrire dans .tmp
2. Valider le contenu
3. Renommer vers finale

Thread-Safe

Verrous asyncio et threading pour les opérations concurrentes.

# Exemple de verrou
async with self._lock:
    await self._save()

Cache Intelligent

Mécanisme de cache avec réconciliation automatique.

# Cache des sessions
if in cache: return
else: load_and_cache()

Intégrité des Données

Validation complète avant chargement des données.

# Validation Pydantic
class SessionMeta(BaseModel):
    session_id: str
    # validation auto

Portabilité

Fonctionne sur tous les OS et terminaux.

# Chemin multi-plateforme
session_dir = Path.home() / ".vibe/sessions"
